## Ask questions about ROR

Email [support@ror.org](mailto:support@ror.org) with any and all questions about ROR: general questions, curation questions, technical questions.

## Suggest changes or additions to ROR records

Anyone can suggest additions or updates to ROR records via a public [request form](http://curation-request.ror.org). You do not need to be affiliated with an organization to suggest changes to the organization’s record in ROR. [Read more about how the registry is curated](https://ror.org/registry/#curation-model).

## Report a bug or request a feature

To report a bug or submit a feature request for ROR, create an issue on [the ROR Roadmap on GitHub](https://github.com/ror-community/ror-roadmap/issues/new/choose).

## Book a time to talk about any and all ROR issues

Want to talk to a live person in real time? You can [book a 30-minute Zoom call](http://calendly.com/ror-chat) with Amanda French, Technical Community Manager for ROR.
